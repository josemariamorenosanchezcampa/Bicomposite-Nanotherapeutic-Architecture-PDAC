# Audit of Zenodo v7.1

Source record: DOI **10.5281/zenodo.22035446**.

Corrections in this candidate: synthetic/in-silico labeling of the 100-row workbook unless independent experimental provenance is supplied; removal of the automatic “MMP9 invasive niche” label; replacement of machine-specific paths; removal of automatic pip installation; distinction between transcriptomic UMAP and anatomical/spatial mapping; documentation that `umap_clusters.png` was described in v7.1 but absent from the six-file archive; addition of provenance, methods, reproducibility, scope, citation metadata, checksums and tests.

The original XLSX, CSV and two deposited PNG files are preserved byte-for-byte. The required GEO HDF5 input is not redistributed, so full numerical regeneration has not yet been executed from this candidate alone.
